# Banking Simulator

## Overview

Banking Simulator is a full-stack banking management application designed to simulate core banking operations such as account creation, deposits, withdrawals, balance inquiries, and transaction management. The project follows a modular architecture with separate frontend and backend components, providing a realistic banking workflow and user-friendly interface.

## Features

* Create and manage customer bank accounts
* Deposit and withdraw funds securely
* View account details and transaction history
* Real-time balance updates
* Admin dashboard for account monitoring
* Transaction logging and record management
* REST API integration for banking operations
* Email alert and notification support
* Agile-based development and testing approach
